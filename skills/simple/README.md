# simple

A reply style: short, plain, human answers with no filler, no flattery and no AI tells. It
applies to chat replies only; code, commits, PR bodies and docs are written normally.

Active on every reply once installed. Say **"normal mode"** to turn it off and **"simple mode"**
to turn it back on. While **hush** runs, hush wins: the only message is its final line.
